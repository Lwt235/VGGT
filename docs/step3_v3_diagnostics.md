# Step 3 v3 冻结权重机制诊断

**C11 向内折返对写回位姿最敏感。** 离线只替换写回位姿后，C11 的平均世界 EPE 从 1.555 降到 0.595 m，末态参考表面到地图中心距离从 0.698 降到 0.157 m。只替换写回深度没有拉直轨迹。种子描述子实际漂移很小，完全锁定外观也未挽回 781/797。两段自然流多数失定位帧的三个候选都达不到判据。直接放开 T1 也会让 C11 更差。

使用 `dc18484` 的模型、`configs/step3_v3.yaml` 和冻结的 Step 3 v3 1500 步检查点。保留 C11 自然流 51、robotics 自然流 16、C11 分段流 79 个查询，恢复归档帧序和首帧米制规范，无后对齐。候选都由当前 RGB/K 和预测状态生成。Oracle 仅在脚本内、模型与 Writer 完成前向之后变换待融合高斯，前向仍接收 RGB/K 和三维记忆，上一帧跟踪先验仍存预测位姿。

## D1 · 种子漂移、共视与背景拖拽

C11 的 180 个锁定种子基元，中心和协方差逐步变化均为 0。到第 42 步，特征 `1 − cosine` 的均值 / P90 / 最大值为 **1.4e−5 / 4.0e−5 / 3.31e−4**，不透明度绝对变化为 **0.001063 / 0.004204 / 0.011571**。两组数值在自然返回 9 步内均保持稳定。完全锁定外观前后，781/797 的种子候选几乎重合。现有数据支持优先排查匹配与初始化，外观污染对这次闭环失败的影响很小。

评测端将每个有效查询像素投影到种子 RGB-D，用 `0.10 + 0.02z` 米深度一致性判断共视。一个 patch 的有效像素超过一半才入组，组内匹配表面占比至少一半才归为共视。按连续像素共视比例分摊权重，9 个返回帧有 **81.6%** 的解算权重落在非共视部分。固定划分登记的 781 和 797 真实种子表面共视率分别为 22.84% 和 27.81%。在本次诊断分辨率上，797 的 129 个非共视 patch 平均 `p_match=0.167`，50 个共视 patch 均值为 0.290。两组数量差使非共视组仍占 **72.3%** 的 `p_match × c_depth`，且两组各有 8 个 `p_match≥0.5`。非共视软锚点质心在 `(0.23, −0.54, 3.10)` m，共视组在 `(−0.23, 0.15, 1.76)` m。797 白化矩初值的视轴与种子中心方向余弦为 **0.994**，随后在错误视点上渲染出 178 个可见 patch。这组现象符合弱匹配累积拖动初值的机制，也解释了为何预测可见区域大而刚体内点率低。

## 对 Step 3 v4 的建议

1. **优先减少不可靠位姿下的地图污染。** 把跟踪参考置信度与写入置信度分开，保留预测轨迹，给 global 回退和低外观一致性写入一个非零的软支持质量，并考虑对远离稳定表面的新身份延迟确认。用候选质量和正常探索区写入量同时验证。良好的可见刚体内点率可以建立局部位姿候选，跨步长全局正确性还需要独立证据。
2. **把部分共视重定位改成对应质量问题。** 优先验证以描述子双向一致性、匹配间隔和 patch 空间分布形成若干相互独立的种子位姿初值。在各候选的实际重叠上验真。797 的错配包含大量高置信 patch，单纯减少选点或更换候选排序无法补齐缺失的正确对应；冻结种子外观可以保留为低成本对照。
3. **保留保守 T1，单独核查远距深度。** 先改善大步位姿候选与稳定地图写回，再测试哪些可观测特征能预测 raw 精化的正向增益。robotics 的远距压缩需要独立修复或训练对照；把现有 `z_cam` 普遍替换进前沿没有数据支持。
