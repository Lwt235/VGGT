## 改动与原因

- 将 O5/O6 注入移到第 4 号可训练 global block **之前**，确保该块融合记忆进 patch 和 camera token。单测检查同层 camera token 确实受注入影响。
- 每个训练 step 采样均匀 SO(3) 和各轴 ±3 m 平移，在 build_memory 前左乘建图 c2w，并同步变换目标 c2w、世界点。评估/绘图 G=I。随机规范不进入 QueryInput，固定单图不能背出新的世界系。
- T0 用冻结 DINO patch 和归一化相机射线，与公共高斯潜特征、协方差尺度、alpha 跨注意力匹配，逐 patch 聚合世界锚点和熵置信度；空间网格特征预测带符号权重，锚点差构造连续 6D 世界旋转，世界锚点加旋转下的局部平移构造 c2w。不是 SVD/Umeyama、ICP 或后对齐。单测检查整体记忆刚体变换时 T0 的规范等变性。
- O5/O6 采用 1024 通道零门控，分支输出先 LayerNorm 再乘 tanh(gate)。O6 Query 加 opacity 门控世界中心 PE 和世界射线；Key 中心 PE 保持无衰减高频。深度特征做 log1p/有界缩放，显式正系数射线邻域与遮挡先验打破初始均匀注意力。
- 先运行原生 DPT 取相机点，再池化到 patch，用 T0.detach() 得到 X_T0；联合 O5 世界坐标残差、opacity、深度方差、相机射线和空间 token，卷积网格头预测 ΔT，T1=T0.detach()@ΔT。分别监督两级位姿、粗/精世界点和匹配锚点；旋转采用 atan2 测地角。
- heads/pose LR=3e-4、门控=3e-3、native=3e-6；DINO 冻结。降低原生 DPT 抢跑速度，给 Reader/门控实际学习空间。
