## 改动与先行验证

实现提交`7e5de84`：

- 局部深度锚定去掉v4的全图gamma。每个patch计算`w=sigmoid(head)*opacity/(1+relative_variance)`、`ratio=clamp(O5_depth/native_patch_depth,0.25,4)`，原生相机点乘`1+w*(ratio-1)`；置信度尾层bias=+1。零opacity严格不修正该patch。
- **具体插值选择须说明清楚**：为满足逐patch绝对隔离，当前将每个1×1比例独立以bilinear提升到14×14，因此前向等效块常量，未做跨patch平滑插值。V1/V5确有条带和patch边界；不能将这个实现描述为跨patch平滑的双线性场，也不能用算子的局部隔离单测宣称完整O5/O6+DPT/位姿输出严格局部。
- T1输入在T0_read处由原生点局部校准；最终在T1.detach处重新渲染，再从raw点独立锚定，避免重复校准。最终世界变换仍用T1.detach。保留v3原生相机L1=0.05、最终相机L1/相对深度各0.2及其余核心设计。
- 建图帧no_grad运行与查询一致的冻结单帧前缀，到frame块4之后/global块4之前停止；Writer与查询latent投影都输入[shallow,pre_inject]。公共记忆只有mu/Sigma/alpha/z，没有图像、token或KV字段。
- 读入微扰改为[0,3°]/[0,6cm]连续幅度；精化增量乘空间上下文小初值置信门控（bias=−2，初值约0.119），零残差/无覆盖仍恒等。最终点损失不直接回传T1。
- Full连续18k训练器在3000步之后只执行非有限、持续断梯度与配置的跨场景EPE门禁；本次确实触发最后一项，没有沿用v3的单帧尾部停止规则。

Full启动前全部74项`REQUIRE_GSPLAT=1`严格测试通过，包括局部锚定擦除隔离/空记忆恒等、对称上下文无历史状态、连续微扰、精化门控及v3几何/梯度测试。独立12步官方初始化Full profile正常，峰值4.62GiB。正式Full再次全新初始化，没有复用profile或smoke检查点。

训练后最终严格复验 **76/76通过**，日志`results/step2_v4_full_seed17/final_tests.log`。新增两项覆盖单帧基线输入/梯度隔离、固定物理共视分组；测试通过不等于验证误差通过。

这定位了下一步的具体对象：局部乘法缩放对原生x/y射线误差与patch边界的影响、置信度回落的梯度原因，以及T1相对残差在干净未见初值上的偏置。独立tile上采样带来的条带也是当前实现选择，不能直接归咎于所有局部锚定方法。尚未通过新的实验确认其中哪项主导，不在此虚构修复成效。

O6仍有物理选择性：robotics归一化熵0.476，3σ预测射线邻域注意力质量0.462，对应均匀分布仅0.00507。分支活跃与能量下降没有解决最终几何退化。
