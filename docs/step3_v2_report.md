## 四项实现


旧版自然流 Full 的世界点 EPE 为 C11 **1.595 m**、robotics **1.227 m**。旧版产物 `results/step3_streaming_seed17` 和 Step1/2/2b 全部只读；本次新目录为 `results/step3_v2_seed17`，从 Step2 Full18k 热启动，没有使用旧 Step3 权重续训。

1. **种子世界规范保护。** 种子 `c2w=I`，仅种子允许 RGB-D。初始融合后支持质量设为32，并用三维身份锁固定种子的均值和协方差；特征与不透明度仍可平滑更新。新观测使用原稳定空间关联，已融合身份不会因尺度频带跨界反复重新哈希。
2. **流式专用局部尺度传播。** 已知表面的可靠度采用饱和覆盖 `(opacity/0.25).clamp(0,1)/(1+rel_var)`，乘温和置信调制。渲染/原生 patch 深度比限制在 `[0.25,4]`，在对数域做四步四邻域扩散，传播质量按距离衰减；没有可见参考和有限传播范围之外严格回退比例1。修正沿标定像素射线双线性上采样，不引入全图单标量尺度。Step2 与旧 Step3 的默认读取行为保留。
3. **几何、外观共同检查写入。** 几何检查使用预测位姿下射线到后验椭球的最小马氏距离，统计 `p_match>0.4` 且 `m²<=4` 的 patch 比例；独立外观检查使用 O5 重渲染潜特征与注入前查询潜特征的余弦，以及相对深度一致性。安全检查不通过时写质量严格为零，学习调制不能绕过该拒绝。关键帧条件使用上次接受写入的预测位姿差和当前未知前沿比例；冗余帧只读。查询潜特征不由已注入的记忆反向制造外观一致性。
4. **稳定地标候选。** 公共记忆达到384个基元、支持质量≥2的地标至少16个时，除全量匹配外再运行地标掩码候选。候选选择只使用模型自身的鲁棒射线–椭球证据及 O5 特征/深度吻合；不输入查询真值。选择地标后 T1 使用同一匹配掩码，criterion 也按实际候选支持生成匹配监督，避免对被排除的噪声高斯强制赋正标签。公共记忆本身不删除、不按2048读取预算截断。

持久状态只包含三维高斯、逐高斯标量支持、种子锁，以及上次接受写入的预测4×4位姿。Local-W另保留最近W步三维候选及其支持；到期种子也正常淘汰。`t>=1` 仍只接受 `QueryInput(rgb,K)` 和上一空间状态，没有 GT 位姿/深度输入，也没有历史原图或帧级2D KV。


## 训练、接口与多卡接管

只读加载Step2 Full18k：results/step2_v5_full_seed17/training_state_18000.pt，未从旧Step3状态热启动。固定原step2_splits.yaml、seed17、168×224，冻结原生VGGT，保留经过冻结层的输入梯度，训练约656万空间参数。

训练轨迹12–16帧，按原配对序列索引采样步长1–4，相邻真实表面共视至少10%，包含探索、宽跨度折返与徘徊。每5个查询detach三维状态并反传，整段完成后更新优化器；未使用可选的前段no_grad减负。完整核查3000条连续更新记录、4000条轨迹和52050个非种子训练查询：全部属于原train和train_frame_ids，无留出帧或val参与训练。

仅t=0允许初始RGB-D并固定c2w=I。t≥1引擎仅接收QueryInput(rgb,K)与3D状态，预测正深度/预测位姿写回。GT仅在独立criterion或评测中使用；无历史RGB、2D KV、事后对齐或ICP。

用户解除串行限制后，在日志2582步附近核实完整2500步检查点且无training_state.tmp，再核实UID1020、/proc/PID/cwd和准确cmdline，仅向本项目单卡训练进程发送SIGINT。未保存尾部日志归档至metrics_interrupted.jsonl；恢复保留模型、Adam及原余弦学习率进度。

2501–3000步采用3卡轨迹DDP：仅注册原空间参数引用，不复制/广播冻结主干；find_unused_parameters=True，每5帧同步反传且各rank段数一致。种子为17+rank*10007+zero_based_step，各rank独立轨迹，平均梯度。仅rank0写日志与原子latest，标准参数名无module.前缀，保存各rank RNG；恢复只豁免新增并行运行元数据。新增测试验证了Adam动量、调度与分rank RNG恢复。

最后500次更新的有效batch从1变3，共4000轨迹。因此不声称与原单卡后500步采样轨迹或v1训练计算量相同。单卡末100步约5.4秒/轨迹，DDP约6.2秒/更新、每更新3轨迹，**轨迹吞吐约2.6倍，固定更新次数的墙钟没有获得3倍加速**。

首次三卡试跑在初始PCIe P2P同步阻塞，未进入正式训练；只结束核实属于本项目的试跑，采用进程级NCCL_P2P_DISABLE=1、NCCL_IB_DISABLE=1后两步真实DDP成功。未修改系统、驱动、GLIBC或他人环境。正式训练峰值分配11.33 GiB/进程，观察到的总进程显存约12–13 GiB，低于20 GiB。

并行调度器启动前两次实时检查显存与进程，训练要求每卡至少20 GiB空闲，评测也保留余量。六条独立评测流实际三卡并发；worker只写自己的流目录，最后按原计划顺序合并，避免并发覆盖。

最终checkpoint和调度器均为3000，72组Adam状态、3份rank RNG完整。仅保留约75 MiB原子training_state.pt与最终training_state_03000.pt hardlink，两者同inode。全部训练、评测和严格测试退出后检查无本项目残留GPU进程，根盘约58 GiB可用。未信号任何他人或归属不明进程。
