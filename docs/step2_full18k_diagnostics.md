## 物理解释与证据边界

T1 优化的是深层查询后验对应椭球上的射线 LM 目标。能量是学习对应、协方差和射线几何共同定义的内部目标，单调接受只说明该目标下降；有偏对应、宽椭球或遮挡误匹配都可能将优化引向更低能量但更差的 GT 位姿。此 evaluation JSON 没有逐查询 LM 能量轨迹，因此不能从该文件给出“每个验证查询能量单调”的实测比例，更不能把训练轨迹能量性质外推为每个验证姿态改善。

擦除影响还经过记忆匹配 → T0/T1 → 最终整图世界变换传播；框外非零既可能来自双线性局部锚定过渡，也可能来自公共位姿变化，单凭本 JSON 无法分解二者份额。四个可视化查询的注入前相机点变化均为零，只能证明这一前置几何支路对干预保持一致；它不能保证后续位姿不变。

应分别解释“空间响应更集中”和“记忆对 GT 有净收益”：绝对变化较集中支持局部因果作用，但负例/姿态退化明确说明其效果并非一致有益。现有固定有共视尾部和零共视失败都应随主报告保留，不能用少数 V5 正例或 LM 能量单调覆盖。
