旧对照`results/step2_full_seed17`完整保留；使用完全相同的`configs/step2_splits.yaml`、168×224尺寸、seed17、18k计划学习率和3000步中期门禁。新运行`results/step2_v2_seed17`从官方完整VGGT权重重新初始化，未读取旧训练参数。

## 改动与验证

1. T0用匹配加权双端散布比恢复尺度初值，径向先验从固定4降至0.04/(scaled_radial+0.5)²；匹配Query加入注入前单帧上下文，仍不读取查询GT。
2. O5使用预测相机系坐标/法向、log深度与相对方差，O6所有中心PE和射线几何转入预测相机系；8频带高频相位未使用物理尺度或协方差衰减。局部锚定置信度使用相对误差/方差；原生与patch深度增加0.2权重相对辅助项，米制世界指标保持不变。
3. T1由原生相机点与T0_read渲染预测；最终用T1处重新光栅化的O5深度锚定原生相机点，再投世界系。干净T0监督与训练读入噪声保持分离。
4. 旧`step2`架构可恢复原行为，新路径只在`step2_v2`启用。

`REQUIRE_GSPLAT=1`全部58项单测通过（含真实CUDA渲染、2/3倍单目低估的6–8m尺度恢复、双路开门控规范不变性、T1重渲染接线与光栅锚定位姿梯度）。双精度几何读取规范误差容差1e-9；真实float32光栅/高频PE分别使用2e-4/1e-3，未要求逐位相同。

12步全新官方权重profile通过，无非有限损失/梯度，实际预留峰值4.62GiB，中位0.56秒/步。profile不作收敛结论；正式运行另行从官方初始化。

## 3000步门禁：停止续训，保留状态

完成3000步后训练进程正常退出，随后完成旧/新检查点的robotics只读深度诊断。**按“仍有异常瓶颈则停止”分支，不启动18000步或No-Memory主基线**。原因是：米制平移与远距锚定确有改善，但T1在未见视角上系统性退化，且一个有共视robotics查询的T0出现严重旋转失败。不能仅凭总EPE的小幅下降宣称健康。
