## O5：可见深度、覆盖与校正权重

以下为 11 个查询的等权均值。可见定义为 T1 重渲染 opacity>0.1；深度误差/相对方差/有效权重进一步要求对应 patch 有效 GT 比例>0.25，仅用于前向后的诊断。

| 指标 | 3k | 18k |
|---|---:|---:|
| 可见 patch 比例 | 0.9877 | 0.9915 |
| 可见渲染深度 L1 / m | 0.2670 | 0.3228 |
| 同位置原生 patch 深度 L1 / m | 0.9898 | 0.9324 |
| 可见相对深度方差 | 0.00779 | 0.00928 |
| 可见局部 confidence | 0.5869 | 0.0727 |
| 可见有效校正权重 | 0.5456 | 0.4998 |

有效校正权重依脚本为 `(0.65+0.35*confidence)*opacity/(1+relative_variance)`，所以 confidence 明显下降没有使物理读取关闭；18k 平均权重仍约 0.50。覆盖率高不能证明投影到了正确表面。362 的可见渲染深度误差从 0.6175 增至 1.0142m，18k 同位置原生误差 0.8033m，可见渲染甚至差于原生；其可见比例仍为 0.96875，有效校正权重 0.3079。这是错误位姿/表面关联下高覆盖仍可能不可靠的实际反例，362 保留在全部统计中。

## T1：两步 LM 单调性与 GT 位姿

3k 与 18k 的 11 个查询均满足三点能量历史逐步不增；各 22 次迭代全部接受 scale=1，没有回退、零步或非有限结果。按各查询初末能量相对降幅等权平均，3k 为 11.95%，18k 为 4.87%。学习到的匹配/协方差跨检查点已变化，绝对能量值不能直接作为检查点质量比较。

|---|---:|---:|
| 旋转误差 / ° | 6.2001→6.6343 | 4.9533→5.3476 |

18k 的 W1 匹配归一化熵均值 0.3447（3k 0.4053），dustbin 均值 0.2486（3k 0.3039）；更尖锐、少拒识的 W1 没有自动带来真实位姿改善。362 的 T0/T1 旋转误差从 3k 的 51.80/51.97° 变为 18k 的 37.24/38.04°，而平移误差从 1.146/1.213m 变为 1.851/1.881m，仍是实质失败案例。即使只作附加诊断看其余十帧，18k 平移均值仍是 T0 0.1793→T1 0.2084m，精化退化不限于362；主统计没有删除任何查询。

## 实际剩余问题

1. 远距深度持续偏浅，O5 提供明显校正但 18k 仍比 3k 更差；近中距世界误差改善不能掩盖该项。
2. O5 confidence 显著降低而65%物理项下限仍使读取活跃；需要结合错误表面/位姿观察，不能以覆盖或低相对方差代替正确性。
3. T1 自身能量严格下降与 GT 位姿改善分离：18k 的平均旋转/平移精化均退化，学习到的椭球与匹配能量仍存在目标偏差。
4. O6 保持物理射线选择性，但相较3k变弱；射线集中度依赖预测 T0，不能作为重定位成功的独立证据。

本任务仅记录已有固定权重的最终诊断，不追加训练或组件消融。后续主报告应将这些问题与四干预、No-Memory/Local 三方和完整验证曲线共同报告。
