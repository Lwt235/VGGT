## 实现与先行验证

- T0：相机散布阻尼0.10×trace(C)/3+1e-6，两步鲁棒权重和散布尺度；三轴叉积补全后Newton–Schulz极分解。共同列尺度归一化避免独立缩放破坏任意斜平面的对称关系。正常6步，数值病态时最多追加6步；无SVD/特征分解。白化/非白化候选仅按同一射线椭球能量比较，进入4步LM。
- O5：可见相对方差加权深度比校准gamma，clamp[0.25,4]、0.05单位伪观测平滑回1，空记忆严格1。尺度来自预测O5与原生相机点，未使用GT；尺度统计detach避免点损失通过读入尺度反拉位姿。校准点同时供精化残差与最终锚定。
- T1：最终重渲染与世界变换都使用T1.detach，阻断最终点损失对精化位姿的代偿梯度。仍训练pose、安全项和既有配对位姿监督。残差/方差改为相对深度单位，平移增量乘可见平均深度还原米制。
- 最终锚定相机点新增L1/相对深度监督各0.2，原生L1稳定项0.05，其他优化器、采样和更新预算保持。

`REQUIRE_GSPLAT=1`全部69项通过，包含三轴平面与斜平面、有少量跨室外点的初值等变性、侧墙LM、2/3倍低估的远距尺度恢复与空记忆严格1、相对精化旋转/米制平移一致性、最终相机损失不回传T1而位姿监督仍有梯度、盲区最终几何监督，以及深度置信度打开方向。

12步全新官方权重profile正常退出：无非有限损失/梯度，峰值reserved4.62GiB，中位约0.59秒/步。正式运行再次全新初始化，profile不作为收敛结论。
