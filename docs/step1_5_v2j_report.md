## 实现

SpatialBootstrap 的旧 4×5 自由位姿 MLP 已取消，仅保留为 LegacySpatialBootstrap 以恢复本项目历史运行。新头的相机深度和几何置信度来自 receive_layer 注入之前的单帧上下文、冻结浅层 patch 与 Kp；相机点完全不读取记忆。正深度 softplus 反投影为相机系点。QueryInput 仍只有 RGB/K。

匹配在 M+1 个槽上 softmax，最后一个为可学习 dustbin；使用 p_match 与内点归一化概率聚合世界锚点。初始权重为 p_match×c_depth×后验空间歧义权重。双端加权去质心，3×3 相机协方差右白化，前两列连续 6D 旋转，平移 X_bar−R P_bar。初解后两次可微 Cauchy IRLS 重加权，tau=0.25 m。小矩系统用 double 求解以避免 TF32 和初期近共面相机点的消减误差，神经特征保持原精度；无 SVD/特征分解，没有预测后对齐。

有充分非退化匹配时，矩层随世界 SE(3) 变换等变。低匹配质量时平滑回退单位阵用于数值安全；单位阵回退本身不能同时对任意世界变换等变，单独列为无观测数值安全验证，不能冒称全域严格等变。阻尼对精确子集不变性存在微小误差，单测使用适当浮点容差。

Criterion 使用真实有效世界点计算 3σ 表面支持率；低于5%时仅训练相机系几何、patch z_cam 与 dustbin 拒识，不监督随机世界系位姿/世界点/锚点，也不执行该帧的 paired 世界位姿一致性。支持 patch 使用全 M+1 概率的软对应正监督；rho²>16 的 patch 监督 dustbin，9–16 留缓冲。paired 分支还把原地图最近支持高斯被擦除的 patch 标为未匹配，不为缺失几何施加世界点恢复目标。真值支持标志只存在于 criterion/evaluator。

所有帧保持评估：有共视查询列世界 EPE、两级位姿与 V5；Brown 3193/3330 的盲区列实测拒识率、相机系 EPE 和 patch 深度误差，世界误差仍保留但不用于卡死本阶段。评估分组来自实际支持率，不在模型中硬编码帧 ID。
